# 미인박명

AI face fortune / physiognomy-inspired beauty simulation MVP.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: leave blank
